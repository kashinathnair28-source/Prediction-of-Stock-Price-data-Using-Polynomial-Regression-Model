# Prediction-of-Stock-Price-data-Using-Polynomial-Regression-Model
## Project Overview
This project applies Polynomial Regression, Orthogonal Polynomial Regression, and Piecewise Polynomial Regression models to forecast stock prices using NASDAQ market data. The study compares quadratic and cubic models using RMSE, MAPE, R², and Adjusted R².

## Dataset
- Source: NASDAQ historical stock data
- Stocks Analyzed:
  - ADDvantage Technologies (AEY)
  - LivaNova PLC (LIVN)

## Methods
- Polynomial Regression
- Orthogonal Polynomial Regression
- Piecewise Polynomial Regression
- Cubic Spline Regression

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Results
The Piecewise Cubic Polynomial Regression model achieved the best predictive performance, providing improved accuracy for capturing nonlinear stock market trends. :contentReference[oaicite:0]{index=0}
